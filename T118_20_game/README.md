# Индивидуальная практическая работа ЕКЕВ • Т118

Вариант: 20. Побег из комнаты

## Как запустить
1. Убедитесь, что установлен Python версии 3.x.
2. Запустите скрипт через терминал: python game.py

## Результаты проверок (4 сценария)

### Проверка 1: Успешная победа (Идеальный маршрут)
1. Выбор действия 1 (Стол) -> получена подсказка 314.
2. Выбор действия 2 (Шкаф) -> введен код 314 -> получен ключ.
3. Выбор действия 3 (Дверь) -> успешный побег на 3-м ходу.

### Проверка 2: Попытка открыть шкаф без подсказки
1. Выбор действия 2 (Шкаф) -> ввод кода 314 -> ошибка (нет подсказки), ход потрачен.
2. Игра продолжается, остаток ходов: 5.

### Проверка 3: Превышение лимита ходов (Поражение)
1. Выбор действия 1 (Стол) 6 раз подряд.
2. На 6-м ходу закончились ходы -> вывод сообщения о поражении.

### Проверка 4: Некорректный ввод в меню
1. Ввод символов abc или 9 в главном меню или меню действий -> вывод сообщения «Некорректный ввод», ходы не списываются.
